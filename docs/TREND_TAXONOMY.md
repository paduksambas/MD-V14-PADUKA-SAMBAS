# MD V14 — Trend Taxonomy

## Domain utama
- **GEO** — geopolitik, diplomasi, konflik, tata kelola global
- **ECO** — ekonomi makro, perdagangan, mata uang, fiskal, utang
- **FIN** — pasar, investasi, perbankan, aset, likuiditas
- **TEC** — teknologi, AI, semikonduktor, komputasi, cybersecurity
- **BUS** — industri, perusahaan, strategi, supply chain, kompetisi
- **ENE** — energi, minyak/gas, listrik, transisi, mineral kritis
- **SOC** — demografi, budaya, pendidikan, perilaku, tenaga kerja
- **ENV** — iklim, lingkungan, pangan, air, bencana
- **SEC** — keamanan, pertahanan, risiko siber, ancaman transnasional
- **HLT** — kesehatan publik, bioteknologi, sistem kesehatan

## Tag tambahan
Gunakan tag seperlunya: `region:`, `actor:`, `sector:`, `horizon:`, `signal-type:`.

## Signal type
- `weak-signal` — indikasi awal, bukti masih tipis
- `emerging` — pola mulai berulang
- `accelerating` — momentum meningkat
- `structural` — perubahan mendalam / jangka panjang
- `shock` — kejadian mendadak dengan dampak luas
- `reversal` — tren berbalik atau kehilangan momentum

## Horizon
- **Immediate:** 0–30 hari
- **Near-term:** 1–6 bulan
- **Mid-term:** 6–24 bulan
- **Long-term:** 2–5 tahun+
